## Opgave

Je hebt net gezien hoe je in dezelfde lus een totaal, een grootste waarde en een teller bijhoudt.

Doe nu hetzelfde met deze Gentse wijken.

1. Bereken de totale bevolking in de tabel.
2. Zoek de wijk met de grootste bevolking.
3. Tel hoeveel wijken meer dan 20000 inwoners hebben.
4. Print de drie resultaten.

#### Verwachte uitvoer

```text
Totale bevolking: 101000
Grootste wijk: Sint-Amandsberg
Wijken boven 20000: 3
```
